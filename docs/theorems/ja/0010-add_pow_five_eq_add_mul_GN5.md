# 0010 — `add_pow_five_eq_add_mul_GN5`

> 本文書は日本語正本です。英語版は本正本からの対応翻訳です。

## Lean の型

```lean
theorem add_pow_five_eq_add_mul_GN5 (g y : ℕ) :
    (g + y) ^ 5 = y ^ 5 + g * GN5 g y := by
  unfold GN5
  ring
```

完全修飾名は `DkMath.FLT.Five.add_pow_five_eq_add_mul_GN5` です。

## 数学的主張

第五冪の二項展開を、基準項 $y^5$ と gap $g$ を因子にもつ残余部分へ分けます。

$$
(g+y)^5=y^5+g\,GN5(g,y)
$$

`GN5` の定義を代入すると、右辺の第二項は二項展開から $y^5$ を除いた全項を正確に集めています。

## 証明全体での役割

本定理は、これまで多項式として分析してきた `GN5` を実際の第五冪へ接続する本体恒等式です。前号までの定理は `GN5` の内部表示を与えましたが、本定理によって初めて $g\,GN5(g,y)$ が第五冪差の「body」であることが等式として公開されます。

後続では本定理から自然数差分形

$$
(g+y)^5-y^5=g\,GN5(g,y)
$$

を導き、さらに $g=z-y$ を代入して Fermat 方程式の $x^5$ と接続します。

## 直接依存する定義・補題

プロジェクト固有の直接依存は `DkMath.FLT.Five.GN5` です。証明は Mathlib の `ring` tactic に依存します。

宣言順では三つの `GN5` 表示補題の後に置かれますが、それらを証明中では呼びません。したがって論理的な直接依存は `GN5` の定義だけです。

## 証明の流れ

1. `unfold GN5` により残余核を展開する。
2. `ring` が左辺の第五冪と右辺の多項式を可換半環の正規形へ変換する。
3. 両正規形の係数一致によって等式を閉じる。

数学的には二項定理

$$
(g+y)^5=y^5+5gy^4+10g^2y^3+10g^3y^2+5g^4y+g^5
$$

の $y^5$ 以外を $g$ で括ったものです。

## Lean 固有の処理

等式は自然数上にありますが減算を含まないため、`Nat.sub` の切り捨て問題は起きません。これが「差を先に書かず、加法形を先に固定する」設計上の利点です。

`ring` は具体的な自然数を計算するのではなく、自然数が可換半環であることを使って多項式恒等式を正規化します。

## 冗長・重複箇所

証明スクリプトは既出の `GN5` 恒等式群と同じ `unfold GN5; ring` です。しかし本定理は内部表示ではなく、第五冪そのものとの接続 API を公開します。数学的役割が異なるため、単純な重複ではありません。

次の `add_pow_five_sub_eq_mul_GN5` は本定理から減法形を導く薄いラッパーです。両者は近いものの、加法形は無条件で半環的、減法形は自然数減算を含むという差があります。

## 最適化候補

証明本体は既に最小に近いです。候補として、`GN5_eq_homogeneous_cyclotomic` と標準差の因数分解から導く証明も考えられますが、依存を増やし、現在の直接的な `ring` 証明より長くなる可能性が高いです。

後続で書き換えに頻用するなら `[simp]` 属性も候補に見えますが、左辺の第五冪を常に展開方向へ書き換えると式が大きくなるため、無検証での属性追加は勧めません。以上は設計提案です。

## 必要 Mathlib import と import 最適化候補

standalone は `import Mathlib` を使用しています。本定理の主要要件は自然数の半環構造、冪、`ring` tactic です。最小 import は Lean ビルドなしでは確定できません。

候補は `Mathlib.Tactic.Ring` と自然数の基本代数モジュールですが、生成済み standalone 全体では後続の数論・代数機能も必要です。本記事では import を変更していません。

## 次に読むべき定理

次は `DkMath.FLT.Five.add_pow_five_sub_eq_mul_GN5` です。

$$
(g+y)^5-y^5=g\,GN5(g,y)
$$

本定理の無減算な加法形から、第五冪差の直接的な因数分解 API へ進みます。
