# FLT5 定理博物館 — 日本語正本

> 本文書群は日本語正本です。英語版は本正本からの対応翻訳として刊行します。

## この博物館について

この展示室は、Lean 4 による指数5の場合のフェルマーの最終定理の形式化を、入口から依存順に一宣言ずつ読むための定理解説集です。

証明全体を一度に要約するのではなく、定義・構造体・補題・定理を個別の展示物として分離し、それぞれがどの事実を受け取り、何を次へ渡すのかを記録します。

本刊行物は、次の役割を兼ねます。

- FLT5 証明の読解順路
- 宣言間の依存関係台帳
- Lean 固有処理の解説書
- 冗長箇所と再構成候補の監査記録
- Mathlib import 最適化の調査帳
- Comparator 向け小課題の素材集

## 正本と翻訳

日本語版を正本とします。英語版は、日本語正本の内容、定理名、数式、節構成を保った対応翻訳です。

日英で解釈差が生じた場合は、日本語正本を基準とします。ただし数学的・形式的な最終根拠は、常にリポジトリ内の Lean ソースです。

## 番号規則

各記事は4桁の連番と宣言名を共有します。

```text
0001-DeclarationName.md
0002-NextDeclaration.md
...
```

番号は standalone ファイル上の単純な出現順ではなく、証明を理解するための依存順を表します。日英版では同じ番号とファイル名を使います。

## 各号の標準構成

各記事には原則として次を収録します。

1. Lean の宣言と完全修飾名
2. 数学的主張
3. 証明全体における役割
4. 直接依存する定義・補題
5. 証明または構成の流れ
6. Lean 固有の型変換・書き換え・tactic
7. 冗長・重複箇所
8. リファクタリングと最適化候補
9. 必要な Mathlib import と import 最小化候補
10. Comparator challenge 化の可否
11. 次に読むべき宣言

Lean ソースから直接確認できる事実と、解説上の解釈・推論・未検証の改善案は区別して記します。

## 根拠資料

第一の根拠は、このリポジトリ内で Lean の kernel により検査されるソースコードです。

既存の日本語・英語 PDF は、証明経路や数学的背景を説明する補助資料として参照します。ただし PDF の記述が Lean 宣言の型や実装を上書きすることはありません。
