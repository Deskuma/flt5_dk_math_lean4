# 0049 — `pow_five_mod_five`

## 1. 対象宣言

```lean
theorem pow_five_mod_five (n : ℕ) :
    n ^ 5 % 5 = n % 5 := by
  rw [Nat.pow_mod]
  have hn : n % 5 < 5 := Nat.mod_lt _ (by decide)
  interval_cases h : n % 5 <;> norm_num [h]
```

完全修飾名は `DkMath.FLT.Five.pow_five_mod_five` である。

## 2. Lean の型

```lean
(n : ℕ) → n ^ 5 % 5 = n % 5
```

任意の自然数 `n` に対し、その第五冪と底自身は 5 を法として同じ剰余を持つ。

## 3. 数学的主張

数学的には

$$
n^5 \equiv n \pmod 5
$$

を自然数の剰余演算で表した定理である。これは素数 5 に対するフェルマーの小定理の特殊例だが、本証明は一般定理を呼ばず、`n % 5` が取り得る五つの値を直接検査する。

## 4. 証明全体での役割

この補題は、FLT5 方程式

$$
x^5+y^5=z^5
$$

を法 5 へ写した際に、第五冪を底へ落とすための正規化規則である。後続では

$$
x+y \equiv z \pmod 5
$$

という一次の合同関係を抽出し、ある座標が 5 で割れる場合に差 `z-x` または和 `x+y` が 5 で割れることを導く。

直前の `five_not_dvd_x_of_branchB` が Branch B 候補で `5 ∤ x` を確保したのに対し、本定理はそこから signed Branch A の二方向ルーティングへ進むための合同算術核となる。

## 5. 直接依存する定義・補題

- `Nat.pow_mod`：冪の剰余を底の剰余へ書き換える。
- `Nat.mod_lt`：正の法 5 に対して `n % 5 < 5` を得る。
- `interval_cases`：有限区間内の自然数を各値へ場合分けする。
- `norm_num`：各剰余値 `0,1,2,3,4` に対する数値等式を閉じる。
- `by decide`：`0 < 5` の決定可能な命題を解決する。

FLT5 固有の定義には直接依存せず、純粋な自然数算術だけで閉じる。

## 6. 証明の流れ

1. `rw [Nat.pow_mod]` により左辺を `(n % 5) ^ 5 % 5` の形へ正規化する。
2. `Nat.mod_lt` から `n % 5 < 5` を得る。
3. `interval_cases h : n % 5` により剰余を `0` から `4` まで列挙する。
4. 各場合を `norm_num [h]` で計算して終了する。

証明は合同式の一般理論ではなく、有限状態空間を完全走査する形になっている。

## 7. Lean 固有の処理

`rw [Nat.pow_mod]` は、数学的には自明に見える「先に剰余を取ってから冪を計算してよい」という操作を明示する。これにより `interval_cases` が扱う対象を `n` 全体ではなく有限値 `n % 5` に限定できる。

`interval_cases h : n % 5` は補助事実 `hn : n % 5 < 5` をローカルコンテキストから利用する。生成される五つの分岐では、等式 `h` を `norm_num` の書き換え規則として渡している。

## 8. 冗長・重複箇所

`hn` は証明本文で名前を直接参照していないように見えるが、`interval_cases` が区間上界を推論するために必要である。したがって論理的な未使用項ではない。

一方、この主張自体はフェルマーの小定理や `ZMod 5` の既存補題からも導けるため、Mathlib の一般定理との数学的重複はある。ただし現在の証明は短く、依存が明瞭で、定数 5 に特化した監査可能性が高い。

## 9. 最適化候補

一般化候補として、素数 `p` に対する

```lean
n ^ p % p = n % p
```

を既存のフェルマー小定理から導き、本定理をその特殊化にする方法がある。しかし、その場合は一般的なモジュラー算術 API や型変換が増え、五つの有限場合分けより証明が長くなる可能性がある。

現状の局所目的に対しては、現在の実装は十分に小さく安定している。最適化するとすれば、Mathlib に同型の `Nat` 補題が存在するかを確認し、直接 `simpa` で再利用できる場合に限るのがよい。

## 10. 必要 Mathlib import と import 最適化候補

生成済み standalone ソースは `import Mathlib` で本証明を検証していることを確認できる。

実際に必要な機能は自然数の剰余・冪、`interval_cases`、`norm_num` である。分割元 `SignedBranchA.lean` の正確な import 行はこの監査では取得できなかったため、以下は推測を含む候補である。

- `Mathlib.Data.Nat.ModEq`
- `Mathlib.Tactic.IntervalCases`
- `Mathlib.Tactic.NormNum`

import 最適化を行う場合は、分割モジュール単体でのビルド確認が必要である。本回は Lean ビルドを行っていない。
